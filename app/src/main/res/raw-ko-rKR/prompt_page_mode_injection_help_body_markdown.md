# 모드 주입

모드 주입은 재사용 가능한 프롬프트 블록입니다.

다음과 같은 이름 있는 모드에 사용할 수 있습니다.
- 학습 모드
- 번역 모드
- 코드 리뷰 모드
- 글 다듬기 모드

## 빠른 시작

1. 주입을 하나 만듭니다.
2. 모드를 설명하는 이름을 붙입니다.
3. 시스템 프롬프트 앞이나 뒤 중 위치를 선택합니다.
4. 실제 지시를 내용에 작성합니다.
5. 여러 주입이 동시에 활성화될 수 있다면 우선순위로 순서를 조정합니다.

## 위치

- **시스템 프롬프트 앞**: 전체 행동을 더 강하게 잡아줍니다.
- **시스템 프롬프트 뒤**: 대부분의 추가 지시에 적합한 기본 선택입니다.
