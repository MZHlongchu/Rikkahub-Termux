# Инъекции режима

Инъекция режима — это переиспользуемый блок промпта.

Используйте ее для именованных режимов:
- режим обучения
- режим перевода
- режим ревью кода
- режим правки текста

## Быстрый старт

1. Создайте одну инъекцию.
2. Дайте ей имя, описывающее режим.
3. Выберите размещение до или после системного промпта.
4. Запишите фактическую инструкцию в содержимое.
5. Если несколько инъекций могут быть активны вместе, настройте порядок через приоритет.

## Позиция

- **До системного промпта**: более сильная рамка для общего поведения.
- **После системного промпта**: безопасный вариант по умолчанию для большинства дополнительных инструкций.
