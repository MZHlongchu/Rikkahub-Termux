# Расширения промпта

Эта страница управляет переиспользуемыми блоками промпта.

## Инъекции режима

Инъекция режима — это ручная инструкция, которую можно привязать к ассистенту или разговору.
Она подходит для режимов перевода, обучения, ревью кода или правки текста.

Приоритет задает порядок, если активно несколько блоков. Позиция задает размещение до или после системного промпта.
